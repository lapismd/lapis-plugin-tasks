## Deferred runner issue

The unbatched `pnpm test:storybook` intermittently disconnects its Vitest
orchestrator between files. It reports `Browser connection was closed` and
`rpc is closed, cannot call "createTesters"`, without a failing assertion.
One complete unbatched run passed, but repeated runs reproduced the disconnect.
Serial execution, Node 24, and full headless Chromium did not resolve it.

The user accepted documenting this issue and using batches to close the local
review. The batch runner partitions the complete discovered suite and stops on
any failed shard. It does not retry failed shards or weaken assertions,
accessibility checks, or timeouts. The original command remains available for
investigation; the cause is still open.
