# Tasks catalog provenance

The catalog was copied from `api-server-tasks` `packages/plugin-tasks/ui`
`src/reference` and remapped onto public `@lapismd/design-core` exports.

Copied component names and presentation CSS are retained for visual comparison.
CV-only `JobApplication`, `applicationId`, and `linkedTo` shapes remain in
`src/lib/model` story fixtures. Design Core `TaskDueCalendar` is imported, not
forked. Studio `TasksWorkspaceSidebar` remains excluded.
